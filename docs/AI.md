# AI Architecture

AI is an explanatory layer over verified repository analysis, not the source of truth.

- Provider-independent adapter interface.
- Evidence retrieval and context construction.
- Sensitive-data minimisation.
- Output validation and evidence references.
- Per-user usage limits and caching.
- AI must disclose missing or incomplete evidence.
- Repository content is untrusted and must not be treated as instructions.
- AI must not perform repository write actions.

Core analytics must remain useful when AI is disabled or unavailable.
