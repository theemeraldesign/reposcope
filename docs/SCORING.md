# Repository Health Scoring

## Proposed dimensions

| Dimension | Initial weight |
|---|---:|
| Development activity | 20% |
| Maintenance | 20% |
| Community engagement | 15% |
| Documentation | 15% |
| Issue and pull request management | 15% |
| Dependency health | 15% |

These are approved planning weights, not a validated scoring model.

## Requirements

- Publish metric definitions and calculation methods.
- Include observation windows and data freshness.
- Distinguish unavailable data from poor performance.
- Expose dimension-level evidence.
- Avoid presenting the score as a measure of developer skill or intrinsic software quality.
- Validate the model against representative repositories before launch.
